> **Resmi Kayyum Onaylı Proje**

> (Onaylanmamıştır ama biz öyle yazdık.)

## 📜 Proje Hakkında

Bu proje, insanlığın en temel, en içgüdüsel ve en anlamsız davranışlarından birini **bilimsel kesinlikle** simüle eder:

**Asansör kapısı kapanmak üzereyken o son umutsuz, nefes nefese, "DUR!" diye bağırarak yapılan koşu.**

Bu simülatör:
- Gerçekten çalışır
- Gerçekten yetişemezsin (istatistiksel olarak)
- Gerçekten utanç duygusunu artırır
- Gerçekten hiçbir işe yaramaz ama çok ciddi görünür

## 📊 Bilimsel Temeller

| Parametre | Değer | Kaynak |
|-----------|-------|--------|
| Ortalama yetişme oranı | %12.7 | Uydurma İstatistik Enstitüsü |
| Utanç seviyesi artışı | +340% | Sokak Gözlemleri |
| Merdiven tercih etme oranı | %89 | "Bir sonraki asansöre binerim" diyenlerin %100'ü |
| Kapıya değen parmak sayısı | 1.4/kişi | Acil Servis Kayıtları (uydurma) |

## 🚀 Kurulum ve Kullanım

```bash
# Depoyu klonla (zorunlu değil ama havalı durur)
git clone https://github.com/Tentivory/asansor-kapisi-kapanmadan-once-kosma-simulatoru.git
cd asansor-kapisi-kapanmadan-once-kosma-simulatoru

# Çalıştır (Python 3 gerekli, sabır da)
python3 asansor_kosusu.py
```
